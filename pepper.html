Pepper Semesterproject

In my 4th Semester I worked on a Semesterproject with 6 other Students. In this Project we combined our knowledge about Computer Science and IT-Productmanagement to create an interactive Infoterminal!

MORE INFORMATION

For this Project we had a Pepper Robot with an older Tablet that was attached to Pepper. That Tablet would showcase the Website Application to get all kinds of Information about the HFU but also Furtwangen itself. To animate the Robot we used the Choreograph which is Peppers own Software to animate the Robot with a Node System and the Frontend was made with Jquery and Basic HTML, CSS and Javascript.
My Tasks for this Project were mostly in the Role of the UX Designer, Tester and also some Coding.
